# DataPilot-AI 🚀  
**AI-Powered Exploratory Data Analysis & Insights Platform**

**Live App:** datapilot-ai.streamlit.app  
**Repository:** GitHub.com/MansoorSarookh/DataPilot-AI  

DataPilot-AI is an intelligent Exploratory Data Analysis (EDA) platform that automates dataset inspection, visualization, and insight generation using AI-assisted workflows. The application enables users to upload datasets and instantly receive statistical summaries, visual analytics, and actionable insights — reducing manual analysis time and improving decision-making.

# 🧠 Overview
DataPilot-AI is designed to streamline the data analysis lifecycle by combining traditional EDA techniques with AI-driven interpretation.  

It is particularly useful for:
- Students and researchers performing quick dataset exploration  
- Analysts needing rapid insights without extensive coding  
- Hackathon teams building data-driven prototypes  

The platform emphasizes **usability, speed, and interpretability**.

# ✨ Features

## 📊 Automated EDA

- Descriptive statistics generation  
- Missing value analysis  

## 📈 Interactive Visualizations

# 🏗️ Architecture

**Frontend:** Interactive web UI  
**Backend:** Data processing & analytics engine  
**AI Layer:** Insight generation module  

Workflow:

1. User uploads dataset  
2. Preprocessing & validation  
3. Statistical analysis & visualization  
4. AI insight generation  
5. Results rendered in dashboard

# ⚙️ Installation

## 1️⃣ Clone the repository
git clone https://GitHub.com/MansoorSarookh/DataPilot-AI.git
cd DataPilot-AI

## 2️⃣ Create virtual environment
python -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows

## 3️⃣ Install dependencies
pip install -r requirements.txt

## 4️⃣ Run the app
streamlit run app.py
